# Punchman

An idle ring brawler by **Autoprod**. Stand in the octagon, auto-punch endless waves, spend gold on upgrades, talents and your crew.

- Gold is the only currency. There is no energy meter.
- Works offline as a phone web app (Add to Home Screen).
- All art is original. The ring is an octagon of our own design.
